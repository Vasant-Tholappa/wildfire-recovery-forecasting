# Hero asset and source context

`bobcat_landsat.webp` is illustrative satellite imagery, not a model output or a claimed evaluated location.

- Source: [Bobcat Fire Scorches Southern California](https://science.nasa.gov/earth/earth-observatory/bobcat-fire-scorches-southern-california-147324/), NASA Earth Observatory, 28 September 2020.
- Acquisition: Landsat 8 OLI, 21 September 2020; false-color bands 7–5–2. Burn scars appear dark red, vegetation green.
- Credit: NASA Earth Observatory image by Lauren Dauphin, using Landsat data from the U.S. Geological Survey.
- Original: https://assets.science.nasa.gov/dynamicimage/assets/science/esd/eo/images/imagerecords/147000/147324/bobcatfire752_oli_2020265_lrg.jpg
- Preparation: full original 1152 × 1280 image resized to 900 × 1000, WebP quality 84. No scientific alterations or generated imagery. Responsive CSS crops the display around the central burn scar; the bundled file retains the full frame.
- [NASA reuse guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) permits factual educational/informational use with acknowledgment, without implying endorsement. The image-specific page credits NASA/USGS, not an external copyright holder. No NASA logo or identifiable person is used.
- Verified 14 November 2026. No third-party image-server request occurs at app runtime; the bundled asset is embedded locally.

The revised hero uses [CAL FIRE statistics](https://www.fire.ca.gov/our-impact/statistics), updated 11 November 2026: 1,103,821 acres is a five-year average for comparable year-to-date intervals, not five complete annual totals. The current copy says “California wildfires have burned millions of acres in recent years.” Its source-link tooltip preserves the exact date, value and preliminary status; the opening does not assert a full-year average. This supersedes the previous hero's explicitly 2024 context; no research metric changes.
